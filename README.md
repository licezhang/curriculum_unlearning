# Curriculum unlearning in humans and neural networks

Code, data and analysis for the paper. Everything reported in the manuscript — every
figure and every number — is regenerated by the commands below.

## Quick start

```bash
conda env create -f environment.yml
conda activate curriculum-unlearning

python run.py figures      # regenerate every figure and all reported statistics
```

That takes a couple of minutes on a CPU. It reads the human data and the cached network
outputs in `results/cache/`, and writes the figures plus `results/main_text_stats.{md,json}`.

## The two ways to run

| command | what it does | needs | time |
|---|---|---|---|
| `python run.py figures` | replay: figures and statistics from cached network outputs | CPU | ~1.5 min |
| `python run.py model` | recompute: retrain the yoked networks, rewrite the caches, then replay | GPU | ~1.5 min |
| `python run.py sweep` | the two hyperparameter sweeps | GPU | ~25 min |
| `python run.py all` | sweep, then model, then figures | GPU | ~30 min |

`figures` is the normal path. `model` exists so the caches can be checked rather than
trusted: it deletes `results/cache/*.npz`, retrains both yoked models from scratch, and
rewrites them. Training is seeded, so on the same hardware this reproduces the cached
values exactly — we verified that all 243 reported statistics come back bit-identical.
Across different GPUs, small floating-point differences are expected; the reported effects
are orders of magnitude larger.

**The caches are derived artefacts, not data.** They are committed so the figures can be
reproduced without a GPU, but nothing in them is independent evidence — `run.py model`
regenerates them from the code and the human trial sequences.

## Layout

```
analysis/
  paper_lib.py            the analysis library: models, measures, statistics
  paper_figures.ipynb     every figure, and the statistics report (last cell)
  run.py                  entry point for the commands above
  reconstruct_sweep.py    the Exp 1 hyperparameter sweep (fit to human curves)
  sweep_benefit.py        the curriculum benefit across that grid (Figure 3e, f)
  experiment1_stats.Rmd   human trial-level mixed models, Experiment 1
  experiment2_stats.Rmd   human trial-level mixed models, Experiment 2
  METHODS_NOTES.md        decisions that are load-bearing or easy to get wrong
data/                     the five human CSVs the pipeline reads (Git LFS)
results/
  main_text_stats.md      every reported statistic, as prose, grouped by figure
  main_text_stats.json    the same with structured fields (b, ci, z, p, n, ...)
  cache/*.npz             cached network outputs (see above)
  sweep_exp1*.csv         sweep results
  permutation_cache.npz   the human-network correspondence permutation test
figures/                  the figures, svg and png
task/                     the experiment code participants ran
```

## Where the numbers come from

`results/main_text_stats.md` is the source of truth for everything reported from the
**networks** and for all descriptive and figure quantities. Each row has a key, the
statistic as prose, and its provenance. `main_text_stats.json` carries the same rows with
the values as fields, so a number can be looked up rather than parsed.

Human **trial-level** mixed models are fitted in R (`analysis/experiment*_stats.Rmd`) and
reported separately. This split is deliberate: no Python GLMM we tested reproduces
`lme4`/`GLMMadaptive` on these data — the variational implementation in `statsmodels`
inflates *z* roughly threefold, and a cluster-robust GLM returns marginal rather than
conditional coefficients. See §5 of `METHODS_NOTES.md`.

## Data

The pipeline reads five files from `data/`:

```
exp1_learning_control.csv  exp1_learning_curriculum.csv  exp1_learning_anticurriculum.csv
exp1_test.csv              experiment2_raw.csv
```

They are stored with Git LFS (`git lfs install` before cloning, or `git lfs pull` after).
Set `SIMPLICITY_DATA=/path/to/data` to read them from elsewhere.

## Reproducing from scratch

```bash
python run.py all          # sweeps, retrain, figures, statistics
```

This regenerates everything including the hyperparameter sweeps, which are otherwise
read from `results/sweep_exp1*.csv`.

## Notes

- Networks are **yoked**: one network per participant, trained on that participant's own
  trial sequence in their own curriculum condition. The model has no freedom over its
  training distribution, so condition differences cannot come from how the training stream
  was built.
- `METHODS_NOTES.md` records the choices that matter and the ones that are easy to get
  wrong: where the noise enters, why the initialisation scale is fixed rather than fitted,
  which quantities marginalise noise and which do not, and several claims from earlier
  versions of this project that do **not** survive.
